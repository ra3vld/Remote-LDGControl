1. Выберите плату

    Схема подключения платы ↗

    2. Настройки после установки

    Свой брокер и Wi-Fi настраиваются без регистрации. Устройство можно добавить на rotator.r3v.ru вручную позднее.

    Порт 8883 включает TLS с проверкой сертификата и имени сервера. Другие порты используют обычный MQTT.

    После подключения USB откроется ссылка для входа и согласия владельца. Wi-Fi и данные своего брокера передаются только плате по USB.

    3. Установите прошивку

    1. Подключите плату USB-кабелем с передачей данных.
    2. Закройте монитор порта и программы, использующие устройство.
    3. Проверьте профиль и выберите USB-порт.

    Если после прошивки появились проблемы, повторите установку с Erase device. Полное стирание удалит настройки; их потребуется ввести заново. Без стирания NVS сохраняется.

    Если плата не подключается: удерживайте BOOT, нажмите и отпустите EN/RESET, затем отпустите BOOT. Требуется Chrome или Edge на компьютере с Web Serial.
