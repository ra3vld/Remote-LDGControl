CONTROLLED settings

At each transmission start below 100 W, the controller runs MEM TUNE after selecting the antenna. SWR is monitored throughout transmission: if it stabilizes above the threshold again after returning to normal, MEM TUNE runs again, followed by AUTO if enabled. Persistently high SWR does not trigger repeated tuning. The antenna table applies on the first band detection or a band change; manual selection on the same band is retained. Without TCI, a new transmission is detected after 1.5 s of confirmed zero power. Missing data does not count as a pause.
